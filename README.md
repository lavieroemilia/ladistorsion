# La Distorsión

Sitio web promocional de **La Distorsión**, de Lalo Lanusse — estreno en Madrid.

Página de una sola pieza (HTML/CSS/JS autocontenidos, sin dependencias de build) con:

- Home con título ajustado dinámicamente al ancho del viewport y halo que sigue el cursor.
- Sobre la obra (sinopsis, ficha artística, ficha técnica).
- Elenco.
- Dirección.
- Funciones.
- Contacto.

## Uso

Es un único archivo `index.html` autocontenido: se puede abrir directo en el navegador o servir desde cualquier hosting estático (por ejemplo GitHub Pages, apuntando a la rama `main`).
